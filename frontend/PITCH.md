# QosQanat — хакатон қорғау сценарийі

## Elevator pitch (30 секунд)

> **QosQanat** («Қос Қанат») — қазақстандық 1–11 сынып оқушыларына арналған
> геймификацияланған білім беру қосымшасы. Duolingo механикасы + Brawl Stars
> энергиясы, бірақ **толық қазақ тілінде** және **ҚР мектеп бағдарламасына**
> сай. Интернетсіз ауылдық мектепте де жұмыс істейді — offline-first.

## Негізгі сандар (жатқа айту)

| Көрсеткіш | Мән |
|---|---|
| Қолжазба сұрақтар | **~1 600** (36 сұрақ × пән × сынып + генераторлар) |
| Пәндер | 5: Қазақ тілі, Математика, Ағылшын, Физика, Информатика |
| Сыныптар | 1–11, әр сыныпқа ӨЗ банкі (мазмұн жасқа сай) |
| Тапсырма форматтары | 4: тест, дұрыс/бұрыс, бос орын, жұп сәйкестендіру |
| Математика | Шексіз генератор: Виет, логарифм, туынды, интеграл, ықтималдық |
| Код | ~20 000 жол Dart, 15 автотест, 0 analyzer ескертуі |
| Интернет | Қажет емес (offline-first, Hive) |

## Демо ағыны (3–4 минут)

1. **Кіру** → splash → үй экраны: HUD (деңгей, ақыл, монета), жаңалықтар.
2. **Оқу картасы** → пән таңдау (әр пәнге өз «әлемі»: дала, ғарыш,
   микросхема — анимацияланған фондар). Карта: оқушы өз сыныбына дейінгі
   бәрін көреді, жоғарғы сыныптар жасырын — баланы шатастырмайды.
3. **Сессия** → 12 сұрақ, жеңілден қиынға, 4 формат араласады. Дұрыс жауап —
   дыбыс + дірiл + жасыл жарқыл; қате — жүрек кетеді. 3 жүрек.
4. **Нәтиже** → конфетти, жұлдыздар, XP/монета count-up → level-up модалы
   (фанфара!).
5. **Батл** → оффлайн қарсыласпен жылдамдық жарысы (детерминистік мок —
   серверсіз). Сұрақтар тек өз сыныбы ±1.
6. **Дүкен/Профиль** → аватар кастомизациясы, жетістіктер, квесттер, streak.

## Техникалық артықшылықтар (сұраққа дайын болу)

- **Offline-first**: барлық деректер Hive + SharedPreferences-те. Ауылда
  интернет жоқ мектептерде де жұмыс істейді — Қазақстан үшін шешуші фактор.
- **Қауіпсіздік**: құпиясөздер SHA-256 хэшпен, ЖСН чексум валидациясы,
  API кілттері қосымшаға салынбайды.
- **Performance**: статикалық/динамикалық қабаттар RepaintBoundary-мен
  бөлінген, фон анимациясы 30fps-ке квантталған, суреттер cacheWidth-пен.
- **Сапа**: бизнес-логика Riverpod провайдерлерінде (виджеттерде емес),
  15 автотест мазмұн кепілдіктерін тексереді (сыныпқа сай сұрақтар,
  жауап нұсқаларының араласуы т.б.).
- **Мазмұн әділдігі**: MCQ нұсқалары детерминистік seed-пен араласады —
  дұрыс жауап ешқашан «әрқашан бірінші» емес.

## Жол картасы (сұраса)

1. **AI дауыстық ассистент** (жалғыз online функция): Claude Haiku 4.5 +
   қазақша STT/TTS, Supabase Edge Function proxy арқылы (кілт backend-те),
   бала қауіпсіздігі фильтрлерімен. Жоспар TASK.md-да дайын.
2. 135 визуал асет: маскоттар (Бектұр/Назым), Lottie, дүкен спрайттары.
3. Орыс тілі, dark mode, мұғалім панелі, сынып аналитикасы.

## Ықтимал сұрақтар → жауаптар

- **«Duolingo-дан несі артық?»** — Duolingo-да қазақ мектеп бағдарламасы жоқ.
  Біз тіл ғана емес — физика, информатика, математика, бәрі ҚР бағдарламасына
  сай, бәрі қазақша, бәрі offline.
- **«Контентті кім жасайды?»** — қазір 1 600 қолжазба сұрақ + математикалық
  генераторлар. Келесі қадам: мұғалімдер панелі арқылы краудсорсинг.
- **«Монетизация?»** — freemium: негізгі бағдарлама тегін, premium —
  AI-ассистент, косметика, ата-ана есептері. B2G: мектептерге лицензия.
- **«Неге сервер жоқ?»** — әдейі: оффлайн = қолжетімділік. Батл мок-қарсыласы
  детерминистік, кейін шынайы PvP қосылады.
