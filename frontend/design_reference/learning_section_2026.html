Қараңғы режим · карта

Cosmic Night #0F0F2E базасы — glass жарқырайды, steppe→cosmos градиенті мен неон жиектер.

Іске асыру ескертпелері (Flutter):
• Clay = Container + екі қабат BoxShadow (сыртқы күңгірт + сыртқы ақ) және ішкі көлеңке үшін CustomPainter/inner_shadow.
• Glass 2.0 = BackdropFilter(ImageFilter.blur) + жартылай мөлдір градиент + 1px gradient border + noise overlay.
• Grade gate логикасы: student.grade ≥ node.grade → ашық; әйтпесе frosted + AbsorbPointer + gentle dialog.
• Микро-анимациялар: flutter_animate (squish/glow/bounce) + confetti пакеті нәтиже экранында.
