## 2-БАҒЫТ: AI ДАУЫСТЫҚ АССИСТЕНТ (Бектұр/Назым + Claude API)

> ⚠️ ЕСКЕРТУ: CLAUDE.md-да бұрын «NO voice assistant» ережесі тұрған (өнім иесінің
> бұрынғы шешімі). 2026-06-11 шешім өзгерді: ассистент ҚОСЫЛАДЫ. CLAUDE.md жаңартылды.
> Бұл — қосымшаның алғашқы online функциясы (қалғаны offline күйінде қалады).

### 2.0 Архитектура (жалпы сурет)

```
Оқушы сөйлейді 🎤
   → STT (speech_to_text пакеті, құрылғыда, kk-KZ) → мәтін
   → HTTPS → BIZDIN PROXY BACKEND (Supabase Edge Function)
       → Claude API (Messages, streaming, persona system prompt)
   → жауап мәтіні (stream) → чат UI
   → TTS (flutter_tts, kk-KZ дауысы) → оқушы естиді 🔊
```

Негізгі қағида: **API кілті ЕШҚАШАН қосымшаның ішіне салынбайды.**
APK-ны кез келген адам ашып, кілтті ұрлай алады. Кілт тек біздің backend-те тұрады,
қосымша тек біздің backend-ке сөйлеседі.

- [ ] A5. Тестілік екінші кілт: `qosqanat-backend-dev`

### 2.2 ФАЗА B — Proxy backend (Supabase Edge Function, ~1 күн)

Жобада Supabase дайындығы бұрыннан бар (SUPABASE_SETUP.sql, .env placeholder) —
сондықтан Edge Functions (Deno/TypeScript) — табиғи таңдау. Тегін тариф жетеді.

- [ ] B1. Supabase жобасын құру → `supabase functions new assistant-chat`
- [ ] B2. Кілтті секрет ретінде сақтау: `supabase secrets set ANTHROPIC_API_KEY=sk-ant-...`
- [ ] B3. Edge Function логикасы (`@anthropic-ai/sdk` Deno-да жұмыс істейді):
      - Кіріс: `{ messages: [...], grade: 8, assistant: "bektur", subject?: "math" }`
      - System prompt-ты СЕРВЕРДЕ құрастыру (клиент өзгерте алмайды — қауіпсіздік)
      - `client.messages.create({ model, max_tokens: 1024, stream: true, system, messages })`
      - SSE-мен клиентке streaming арқылы қайтару
- [ ] B4. Қорғаныс қабаттары:
      - Жылдамдық лимиті: 1 қолданушыға күніне ~30 сұрақ, минутына 5 (Supabase KV/таблица)
      - `max_tokens: 1024` қатаң шектеу (TTS үшін ұзақ жауап керегі де жоқ)
      - Кіріс мәтін ұзындығын шектеу (≤500 таңба)
      - Анонимді қолданушы id (қосымша офлайн — тіркелгі жоқ, сондықтан device-id негізінде)
- [ ] B5. Модель таңдауы (баға 2026-06):
      | Модель | ID | Кіріс $/1M | Шығыс $/1M | Рөлі |
      |---|---|---|---|---|
      | Claude Haiku 4.5 | `claude-haiku-4-5` | $1.00 | $5.00 | **Негізгі** — балалар сұрақ-жауабына жылдам әрі арзан |
      | Claude Sonnet 4.6 | `claude-sonnet-4-6` | $3.00 | $15.00 | Күрделі түсіндірулерге апгрейд опциясы |
      Шығын болжамы (Haiku): ~500 кіріс + 200 шығыс токен/сұрақ ≈ **$0.0015/сұрақ**,
      яғни 1000 сұрақ ≈ $1.5. System prompt-қа `cache_control: {type: "ephemeral"}`
      қойсақ қайталама сұрақтар одан да арзан.
- [ ] B6. Persona system prompt (серверде, қазақша):
      - Сен — Бектұр/Назым, QosQanat оқу қосымшасының достық көмекшісісің
      - Оқушы {grade}-сыныпта — түсіндіруді сол деңгейге бейімде
      - ТЕК оқу тақырыптары; қысқа жауап (дауыспен оқылады, ≤4-5 сөйлем)
      - Жауапты дайын бермей, қадам-қадаммен жетелеу (Socratic әдіс)
      - Балаға қауіпсіз: ересек тақырыптардан жұмсақ бас тарту, жеке деректер сұрамау
      - Тек қазақ тілінде жауап беру
- [ ] B7. `curl`-мен тестілеу + қате күйлері (429 rate limit, 529 overloaded → клиентке түсінікті хабар)

### 2.3 ФАЗА C — Flutter: дауыс қабаттары (~2 күн)

- [ ] C1. Пакеттер: `speech_to_text` (STT), `flutter_tts` (TTS), `http` (SSE үшін)
- [ ] C2. Рұқсаттар:
      - Android: `RECORD_AUDIO` + `INTERNET` (manifest), Android 11+ үшін speech қызметін `<queries>`-ке қосу
      - iOS: `NSMicrophoneUsageDescription`, `NSSpeechRecognitionUsageDescription` (Info.plist, қазақша түсіндірмемен)
- [ ] C3. `SpeechService` (lib/services/speech_service.dart):
      - STT: `locale: 'kk-KZ'` (құрылғыда қазақ тілі жоқ болса — ru-RU fallback + ескерту)
      - TTS: `setLanguage('kk-KZ')`, дауыс жылдамдығы балаға ыңғайлы (~0.45)
      - Дыбыс баптауы (`settings.soundOn`) мен дірілге (`AppHaptics`) бағыну
- [ ] C4. Құрылғыда kk-KZ қолдауын тексеру: `speech.locales()` / `tts.getLanguages` —
      жоқ болса UI-да «Қазақша дауыс қолжетімсіз, мәтінмен жазыңыз» деген fallback
- [ ] C5. Жоқ болған жағдай: мәтіндік чат әрқашан жұмыс істейді (дауыс — қосымша қабат)

### 2.4 ФАЗА D — Flutter: ассистент экраны (~2-3 күн)

- [ ] D1. `assistant_provider.dart`: чат тарихы (сессия ішінде), күй машинасы
      `idle → listening → thinking → speaking`, streaming жауапты жинау
- [ ] D2. `AssistantService`: backend-ке POST + SSE streaming парсинг,
      try-catch + timeout (20с), offline тексеру (`connectivity` немесе қарапайым catch)
- [ ] D3. UI — `assistant_screen.dart`:
      - Жоғарыда маскот (AvatarDisplay): listening кезінде wave, thinking кезінде idle
        (premium асет келгенде thinking), жауап кезінде celebrate
      - Чат көпіршіктері (оқушы оң жақ, ассистент сол жақ), streaming мәтін теріліп көрінеді
      - Үлкен микрофон батырмасы: басып тұрып сөйлеу (push-to-talk) + пульс анимация
      - Дыбыс толқыны индикаторы (STT amplitude)
      - TTS ойнап жатқанда «тоқтату» батырмасы
      - Күндік лимит көрсеткіші («Бүгін: 12/30 сұрақ»)
- [ ] D4. Навигация: Home экранына/drawer-ге «Көмекші» кіру нүктесі + go_router маршруты
- [ ] D5. Күй-хабарлар (бәрі қазақша, AppStrings-те):
      - Интернет жоқ: «Көмекшімен сөйлесу үшін интернет қажет 📡»
      - Лимит бітті: «Бүгінгі сұрақтар таусылды. Ертең жалғастырамыз! 🌙»
      - STT қателігі: «Естімей қалдым, қайталап көрші 🎤»
- [ ] D6. Offline-first қағидасы бұзылмайды: ассистент жоқ кезде қосымшаның қалған
